# README screenshots

These are unedited browser captures of the real Picie frontend and backend,
using a disposable local PostgreSQL database and a synthetic demo account.
The photo was composed at 115% zoom to fill the preview, uploaded through the UI,
and its persistence checked after reload. The album is named Mountain escapes.

- `photo-editor.png`: desktop photo preview and editing controls, 1120 × 800.
- `album.png`: desktop album after uploading and reloading, 1120 × 800.
- `album-mobile.png`: the same album at a mobile viewport, 390 × 844.

The color photo shown is *Grand Tetons in Grand Teton National Park*, from USGS.
[USGS source and public-domain designation](https://www.usgs.gov/media/images/grand-tetons-grand-teton-national-park).

These screenshots show the application UI, not a physical frame display.
